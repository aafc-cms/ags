## Versioning

Match version to Drupal core and WxT

## Extensions

The three parts of our versioning system are MAJOR.FEATURE.BUG.

Given the following tag: 11.1.2:

|       |                                                                   |
| ----- | ----------------------------------------------------------------- |
| **11** | Major version                                      |
| **1** | Feature release |
| **2** | Bug fix release between feature releases                           |

# Security Policy

## Reporting a Security Issue


**Validate your code and remove ALL security issues before publishing changes to the public repository!**
If you discover a security vulnerability, please report it privately by emailing us at <aafc.cmswebapps-sgcappsweb.aac@agr.gc.ca>. We take security issues seriously and will respond promptly to assess and address the issue.
